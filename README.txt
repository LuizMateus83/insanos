# Insano Burgers & Pizzas — site mobile

Abra `index.html` no navegador para testar.

## O que já está configurado
- Layout mobile-first inspirado no Instagram enviado.
- Botões de pedido direcionando para o WhatsApp da loja.
- Filtros de cardápio: Todos / Burgers / Pizzas.
- Horário informado no perfil: terça a domingo, 19h às 23h.
- Logo recortada do material enviado.

## Antes de publicar
Substitua os produtos, preços, sabores, fotos reais, endereço e demais informações pelos dados fornecidos pela loja.
